Blanc/Deployed bytecode/Lido CircuitBreaker

Lido’s CircuitBreaker.

A registry of emergency pausers: Lido’s DAO assigns a pauser to each protected contract, and the pauser can pause it for a bounded time. 4,584 bytes compiled by solc 0.8.34, deployed on 30 April 2026 — the corpus’s youngest artifact, and the only one deployed under rules Jaune covers.

Its registry is a Solidity array with three hashed mappings beside it, and its results come in two tiers that trade scope for premises. The history tier proves the registry consistent after any valid history, under hash-separation premises over all addresses. The finite tier replaces those premises with checks the kernel decides, for a single update over an explicit list of addresses — and the live registry on mainnet passes the same decidable check.

What is stored

The registry, and why it needs hash premises.

The registry is a Solidity array of protected contracts with three mappings: from a contract to its pauser, from a contract to its index in the array, and from a pauser to the number of contracts it guards. Mappings live at Keccak-hashed storage slots, so a proof that they stay consistent must know their slots do not collide — with each other, with the array, or with the fixed slots. Blanc adds no axiom about Keccak-256; it states the separation it uses, and the two tiers state it in two different ways.

Safety, after any history

The history tier: consistency, under universal premises.

After any configured history from a checkpoint holding the code and an empty registry, there is a registry witness of the final storage: assignment and index slots are nonzero exactly for registered contracts and agree with the array; every pauser’s count equals its number of assignments; the zero pauser’s count is zero; and the live pausers’ counts sum to the array’s length (lido_history_l1_l3). And every committed, non-static registerPauser(t, 0) — including one re-entered from inside pause’s external call — removes t with the correct swap-and-pop repair of the array (lido_history_l2_committed).

This tier assumes, at every frame, separation conditions on the registry’s hashed slots that quantify over all 2160 addresses. It is the one family in the corpus whose headline history results still need them. Under a random-function model of Keccak, the chance that such a premise fails is about q·2−94 per frame for q written slots — four key families, each ranging over 2160 addresses or indices, among 2256 slots — but that estimate is a heuristic: no reduction or bound is proved.

Premises the kernel decides

The finite tier: a universal premise traded for a computation.

Its observation, RegistryOn storage entries probes, says that an explicit list of entries is valid and that the array and, for each address in a caller-supplied list of probes, the assignment, index and count words agree with it. A decision procedure, checkRegistryOn, decides it. A successful execution of registerPauser(target, p) for an existing target and a nonzero new pauser takes storage on which the check holds to storage on which it holds for the updated entries — and every separation premise it takes is itself a decidable check on concrete key lists.

Every hypothesis after the call shape is decidable — the separation premises are literally Boolean checks on finite key lists — so for a concrete state the kernel closes them by evaluation, Keccak included. The premises are not idle: a constructed state with one entry and four probes satisfies all of them at once (exampleApplicable). The price is scope: the finite tier says nothing about addresses outside the probes, about inserting or removing targets, or about histories.

The seventh question

The live registry passes the check.

All of the CircuitBreaker’s use lies in forks Jaune covers. At block 26,141,229, 29 explicit probes over 107 storage slots, on which three providers agree, satisfy every field of the decidable RegistryOn check for the 19 live entries — which replaying all 23 PauserSet events since deployment reproduces. The probes cover finitely many addresses, no state root authenticates the reads, and the check was computed outside the kernel; a kernel-checked version of it has not been built.

Where a history can start

Deployment.

Under every covered fork, the recorded creation input, run as a CREATE from the recorded deployer at nonce 0 with 1,000,000 gas, installs the certified runtime at the mainnet address and leaves exactly the constructor’s storage: a pause duration of 1,814,400 seconds (21 days) and a heartbeat interval of 31,536,000 (365 days) (lido_deploy_covered). The finite deployment theorem shows that this storage satisfies RegistryOn [] probes for every probe list passing one decidable check (lido_create_finite_init); the history tier’s empty-registry checkpoint is established under two bounded hash premises. Because the contract was created after BPO2 activated, the historical deployment ran under a covered fork — though, like every deployment here, the theorem is a modeled execution, not a proof of inclusion.

Stated, so it is not inferred

Not claimed.

  • That any target is actually paused, or that pausing succeeds: there is no liveness result at any level, in either tier.
  • That authorization is complete, or anything about setter effects and events.
  • At the history tier, static committed frames and frames under a rolled-back ancestor.
  • At the finite tier, any address outside the probe list, target insertion or removal, and any history.

The claim map’s CircuitBreaker section lists every theorem with its premises, file and line.

Context

Earlier work, and Blanc’s own CircuitBreaker.

Before deployment, Cyfrin checked 41 properties of a pre-deployment revision of the source with the Certora Prover 8.8.1, verifying 38 and reporting three cases of registerPauser as known limitations correct by manual analysis, and matched a local build of the deployed revision to the deployed bytecode. We found no machine-checked verification of the deployed bytecode.

Blanc also contains a reimplementation of the CircuitBreaker in its own language, whose registry integrity is proved for every state reachable along a configured chain, with no premise about the code at any other address. More on Blanc’s CircuitBreaker.
