# PRORATA fixtures

This directory is generated only by `scripts/gen-prorata-fixtures.py` using the
pinned Prague EELS transition tool. The generator derives target-state
expectations from the exact integer model, writes the scenario manifest, and
asserts every outer receipt status, scenario-specific post-state facts, and
that every fixture emits no logs. The suite includes each arithmetic guard,
all three nonpayable wrappers, successful re-entry after checks-effects, a
rejected payout with full rollback, and the frozen G6 offset transcript.

The harness `scripts/check-prorata.sh --no-build` checks the manifest in both
directions, byte-compares every pre-state PRORATA runtime against
`Blanc.prorataCode`, byte-compares canonical arithmetic vectors regenerated by
`scripts/gen-prorata-oracle-vectors.py --check`, and replays every JSON file
through Jaune's Prague fixture runner.

The committed fixture population is created once `Blanc/ProrataCode.lean` is
available. Do not hand-edit generated fixture JSON or `manifest.json`.
