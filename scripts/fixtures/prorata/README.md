# PRORATA fixtures

This directory is generated only by `scripts/gen-prorata-fixtures.py --write`
through Blanc's pinned current-mainnet BPO2 lane. The generator derives the
canonical BPO2 system preallocation and headers from that exact target, checks
target-state expectations against the integer model, and asserts every outer
receipt status, scenario-specific post-state fact, and absence of logs before
writing. Normal mode is read-only and byte-compares all 14 fixtures plus the
manifest. The suite includes each arithmetic guard, all three nonpayable
wrappers, successful re-entry after checks-effects, a rejected payout with full
rollback, and the frozen G6 offset transcript.

The harness `scripts/check-prorata.sh --no-build` checks the manifest in both
directions, byte-compares every pre-state PRORATA runtime against
`Blanc.prorataCode`, byte-compares canonical arithmetic vectors regenerated by
`scripts/gen-prorata-oracle-vectors.py --check`, and replays every JSON file
through Jaune's BPO2 fixture runner. It requires no external target and remains
the CI replay boundary. `scripts/check-prorata-current-mainnet.sh` separately
verifies the shared target and regenerates all documents in memory.

The committed fixture population is created once `Blanc/ProrataCode.lean` is
available. Do not hand-edit generated fixture JSON or `manifest.json`.
